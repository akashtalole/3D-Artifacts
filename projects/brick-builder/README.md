# Brick Builder

A 3D builder for interlocking plastic bricks with the classic dimensions:

- **Dimensions:** 8 mm stud pitch, 3.2 mm plates and 9.6 mm bricks.
- **Parts:** 34 bricks, plates, tiles, 45° slopes and round parts, in 24 colours.
- **Building:** stud snapping with gravity, so parts overhang but never float. Smooth surfaces refuse studs.
- **Tools:** Build, Paint, Erase and Pick, plus rotate and undo/redo.
- **Extras:** auto-save, JSON export/import, PNG screenshots, brick-by-brick replay, and three sample builds.

No build step:

```bash
python3 -m http.server 8000      # from this folder
# open http://localhost:8000/
```
